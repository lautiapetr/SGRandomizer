# SoulGold v.1.1.4 source map

This audit was performed against the ignored checkout
`.work/soulgold-v1.1.4/` at the exact tag `v.1.1.4`. Paths below are relative to
that checkout. They identify formats and ownership; no SoulGold content is
copied into this repository.

## Prototype audit

The original `prototype/randomize.py` was a single 900-line module combining
CLI, parsing, policy, transformations and writes. Its useful behavior was
migrated, with these findings addressed:

- Preview was deterministic and mostly read-only, but apply wrote each file
  immediately; a later exception left earlier files modified.
- One item RNG served both scripts and map JSON, so adding a script occurrence
  shifted unrelated map-item results.
- Wild and scripted Pokémon shared one family mapping rather than independent
  subsystem streams.
- The checked-in unit test computed the checkout root incorrectly and failed in
  `setUpClass`, so zero tests ran.
- Hidden items were read from `hidden_item_events`, but v.1.1.4 stores all 55
  audited hidden items as `bg_events` with `type: hidden_item`.
- Compatibility validation accepted an untagged Git checkout because a failed
  exact-tag lookup was treated like a non-Git fixture.
- Regex-based scripts deliberately covered only the command forms listed
  above, while the README implied broader coverage of every gift/static source.
- The repository carried an obsolete ZIP snapshot duplicating the prototype,
  complicating review and release provenance.

The package now separates planning from committing, validates real Git tags,
uses named RNG domains, tests synthetic formats, and states uncovered source
families explicitly.

## Audit counts and invariants

At v.1.1.4 the main encounter JSON exposes four method keys. The checkout has
366 item-ball object events and 55 hidden-item background events. Script search
also found command and macro families beyond the phase-1 adapters, which is why
the coverage distinctions above are explicit.

For every apply, the manifest records the exact supported tag, normalized seed,
named RNG streams, change counts and before/after SHA-256 hashes. The tool does
not invoke the SoulGold build or copy any source file into the SGRand tree.
